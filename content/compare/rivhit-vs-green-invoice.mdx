# ריווחית או חשבונית ירוקה: מה מתאים לעצמאי ולעסק

> **תשובה קצרה:** ריווחית וחשבונית ירוקה (מורנינג) משרתות צרכים שונים. ריווחית היא מערכת הנהלת חשבונות ו-ERP בתמחור שנתי, שמתחילה ב-1,200 ₪ לשנה, ולה מסלול ללא הפקת חשבוניות. חשבונית ירוקה מתמקדת בהפקת חשבוניות במסלולים חודשיים, החל מ-29 ₪ לחודש. ההחלטה תלויה במידת הצורך בהנהלת חשבונות מלאה.

## שתי מערכות, שני מיקודים
ריווחית בנויה כמערכת הנהלת חשבונות ו-ERP לעסק: תנועות הנהלת חשבונות, הפקת מסמכים, ניהול מלאי וספקים. התמחור שלה שנתי, והמסלולים נבדלים ביכולות. חשבונית ירוקה בנויה סביב הפקת חשבוניות והוצאות, עם מסלולים חודשיים ותקרות מסמכים.

ההבדל המשמעותי ביותר הוא שמסלול Basic של ריווחית **אינו כולל הפקת חשבוניות** כלל — הוא מיועד לניהול תנועות הנהלת חשבונות. הפקת חשבוניות וחשבוניות ישראל מתחילות במסלול Plus. בחשבונית ירוקה, לעומת זאת, הפקת חשבוניות קיימת בכל המסלולים.

בדקנו לפי המידע שפורסם באתר הספק ב-16.10.2026. המחירים לפני מע״מ, ויש להוסיף 18% ({{sources:[src_vat_01]}}).

ההבדל בין השתיים נובע מהשאלה מה בדיוק העסק צריך. אם התשובה היא מערכת שתנהל את כל הנהלת החשבונות, ריווחית עשויה להתאים. אם התשובה היא כלי פשוט להפקת חשבוניות והוצאות, חשבונית ירוקה עשויה להתאים.

## מי מתאים למי
- **ריווחית מתאימה ל:** עסקים שצריכים מערכת הנהלת חשבונות מלאה, ניהול מלאי וספקים, ומעדיפים/ות תשלום שנתי אחד והתחייבות שנתית.
- **חשבונית ירוקה מתאימה ל:** עצמאים ועסקים קטנים שצריכים בעיקר הפקת חשבוניות והוצאות, ומעדיפים/ות מסלול חודשי עם עלות כניסה נמוכה.
- **ריווחית Plus מתאימה ל:** מי שמפיק/ה מסמכים ללא הגבלה וצריך מספר הקצאה וגישה ל-API.

## עלות בפועל
העלות השנתית של ריווחית (1,200–2,400 ₪ לפני מע״מ) גבוהה ממסלול Basic של חשבונית ירוקה, אך היא כוללת כלי הנהלת חשבונות רחבים. בחשבונית ירוקה יש לחשב גם מסמכים מעבר לתקרה. כדי להעריך את העלות לפי היקף המסמכים, אפשר להשתמש ב-{{link:invoicing-cost}}.

## יתרונות וחסרונות
**ריווחית — יתרונות**
- מערכת הנהלת חשבונות ו-ERP מלאה, כולל מלאי וספקים ב-Pro.
- מסמכים ללא הגבלה ב-Plus וב-Pro.
- תמיכה טלפונית.

**ריווחית — חסרונות**
- מסלול Basic אינו כולל הפקת חשבוניות.
- מודול API ומשתמש נוסף בתשלום נפרד.
- התחייבות שנתית ותמחור גבוה יחסית.

**חשבונית ירוקה — יתרונות**
- מסלול כניסה חודשי נמוך (29 ₪).
- הפקת חשבוניות בכל המסלולים.
- אפליקציות לנייד.

**חשבונית ירוקה — חסרונות**
- תקרת מסמכים בכל מסלול, עם חיוב על חריגה.
- API רק מ-Best ומעלה.
- כלי הנהלת חשבונות מצומצם יחסית.

## איך בוחרים בין השתיים
השאלה הראשונה היא היקף הפעילות. עסק קטן שצריך להפיק חשבוניות ולעקוב אחרי הוצאות עשוי להסתפק בחשבונית ירוקה, בעוד עסק שצריך לנהל תנועות הנהלת חשבונות, מלאי וספקים יצטרך מערכת כמו ריווחית.

השאלה השנייה היא אופן התשלום. ריווחית מחייבת תשלום שנתי והתחייבות שנתית; חשבונית ירוקה מאפשרת גם מסלול חודשי. עבור עסק בתחילת הדרך, מסלול חודשי זול מאפשר גמישות.

השאלה השלישית היא הצורך ב-API. בריווחית מודול ה-API עולה 199 ₪ בנוסף למסלול; בחשבונית ירוקה ה-API כלול מ-Best ומעלה.

## שיטת הדירוג
ההשוואה כאן עובדתית, לפי הנתונים שפורסמו. שיטת הדירוג המלאה מפורסמת באתר ומשקלת מחיר, התאמת פיצ'רים, תמיכה, אמינות ושקיפות. אין בציון כל התחשבות בתשלום. מידע מלא ב-{{link:methodology}}.

## סוגי מסמכים ומה כל מערכת מפיקה
ריווחית מיועדת להנהלת חשבונות מלאה: תנועות, מסמכים, מלאי וספקים. חשבונית ירוקה מתמקדת בהפקת חשבוניות והוצאות, עם תקרות מסמכים.

על פי הנתונים שפורסמו, ריווחית דורשת מסלול Plus לפחות לצורך הפקת חשבוניות ומספר הקצאה, ובמסלול Pro נוספים ניהול מלאי וספקים. בחשבונית ירוקה, הפקת חשבוניות ומספר הקצאה קיימים בכל המסלולים.

לכן, עסק שצריך גם הפקת חשבוניות וגם ניהול מלאי יצטרך להשוות בין ריווחית Pro לבין שילוב של חשבונית ירוקה עם כלי מלאי נפרד. בחירה כזו תלויה בהיקף הפעילות ובמורכבות שלה. בנוסף, שווה לבחון אם בעתיד יידרש גם ניהול מלאי, מכיוון שמעבר בין מערכות בהמשך כרוך בהעברת נתונים ובהסתגלות מחדש של הצוות. את השיקול הזה כדאי להביא בחשבון כבר בבחירה הראשונית, ולא רק לפי הצורך הנוכחי.

## שאלות נפוצות
**מה ההבדל המרכזי בין השתיים?**
ריווחית היא מערכת הנהלת חשבונות ו-ERP; חשבונית ירוקה מתמקדת בהפקת חשבוניות והוצאות.

**האם מסלול Basic של ריווחית מפיק חשבוניות?**
לא. לפי הנתונים שפורסמו, Basic כולל תנועות הנהלת חשבונות ללא הגבלה אך ללא הפקת חשבוניות; הפקה מתחילה ב-Plus.

**כמה עולה ריווחית?**
Basic 1,200 ₪ בשנה, Plus 1,700 ₪, Pro 2,400 ₪ (מחיר מבצע "12 במחיר 10"); מחיר מחירון 1,440 / 2,040 / 2,880 ₪.

**האם צריך לשלם על API?**
בריווחית מודול API עולה 199 ₪; בחשבונית ירוקה API כלול מ-Best ומעלה.

**האם המחירים לפני מע״מ?**
כן. יש להוסיף 18% ({{sources:[src_vat_01]}}).

**האם יש הגבלת מסמכים?**
בריווחית Plus וב-Pro אין הגבלת מסמכים; בחשבונית ירוקה יש תקרה לכל מסלול.

**מה לגבי מספר הקצאה?**
ריווחית תומכת במספר הקצאה מ-Plus; חשבונית ירוקה בכל המסלולים.
