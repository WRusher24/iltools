## C. דרישות נלוות שנבדקות כ-BLOCKER

1. עמוד עם `{{aff:…}}` חייב לכלול גם אמצעי גילוי נאות (`{{slot:AFF-1}}` או טקסט גילוי) — אחרת BLOCKER.
2. עמוד עם `regulated: true` חייב לכלול `<!-- DISC-PENSION -->` או token מקביל — אחרת BLOCKER.
3. כל מספר המכיל ₪ או % חייב להיות באחד משני מצבים: (א) מופיע ב-`docs/content/DATA_REFERENCE.md`,
   או (ב) מסומן כ"דוגמה/הדגמה" ויש לידו `{{chart:…}}`/הנחות. אחרת HIGH (לבדיקה ידנית).
4. אין להמציא ציטוט, המלצת משתמש, או "ביקורת לקוח" שאינם קיימים — BLOCKER.
5. אסור `http://` גלוי או קישור אפיליאייט גלוי — להשתמש ב-`{{aff:slug}}`. קישור `{{link:slug}}` חייב להתאים ל-slug באינוונטר.
