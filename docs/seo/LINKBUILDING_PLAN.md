# LINK-BUILDING & PR PLAN — IL-Tools (Agent 5, 90 days)

Built on Agent 2's `docs/research/LINK_TARGETS.md` (thin — expanded here). Goal: earn authority links in Hebrew for a YMYL finance site **without** black-hat tactics.

---

## 1. Data-driven assets (the link magnets)

These earn links because they are **original and citable**, not because we asked:

1. **מדד עמלות הסליקה בישראל** (annual clearing-fee index) — compiled from the published tariffs we already hold (`/data/providers/clearing.json`) plus a documented method. Pages: `/articles/clearing-fees-by-turnover` + a yearly hub. Add `Dataset` markup.
2. **דוח הנטו של הפרילנסר** (freelancer net-income report) — computed scenarios across income levels using the calculators (labeled "הדגמה", assumptions stated). Links to `/tools/freelancer-hourly-rate`.
3. **מדרגות מס ותקרות — סדרת נתונים** (tax brackets & ceilings series) — versioned tables from `/data/rates/*`, `Dataset` markup, re-published each January.
4. **מחשבון מע״מ / מחשבון נטו לעצמאי** — free tools that naturally attract citations and embeds from accountants' blogs and freelancer communities.

Rule: every asset states its **method** and **sources**; no pay-to-publish; no sponsored links without `rel="sponsored"`.

## 4. Hebrew outreach rules

- Short, specific, data-first. Lead with the number/insight, not the brand.
- Offer the dataset/chart for reuse with attribution; make it easy (clean table, source line).
- Never offer money, gifts or "links for links". No reciprocal-link schemes.

## 5. Wikipedia / Wikidata

- Only if the entity becomes genuinely notable (press coverage + independent sources). Do not create a self-serving article. If a Wikidata item is warranted, keep claims neutral and sourced.

## 6. What to avoid (hard NO)

- PBNs, link farms, paid links **without** `rel="sponsored"`, comment spam, forum profile link-drops.
- Exact-match anchor spam; widget/embed-backlink schemes with keyword anchors.
- Doorway pages, guest posts on irrelevant sites, "partners" pages of low-quality aggregators.

## 7. Measurement

Track in the roadmap dashboard: referring domains, new earned links by asset, brand mentions, and **quality** (domain authority tier of referrers). Report monthly; no KPI is "links built" alone.
